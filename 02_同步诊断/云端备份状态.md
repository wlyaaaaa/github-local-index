# 云端备份状态（派生导航）

- `document_role=derived_navigation`
- `authoritative=false`
- `derived_from=E:\PCConfig + owning backup projects + live providers`
- `observed_at=none`
- `freshness=not_a_snapshot`
- `expires_after=immediate`

本公开索引不再保存 Drive/rclone 对象数、字节数、备份任务返回码、计划任务状态、
本机路径或“当前已同步”结论。此类数据属于 PCConfig、Task Scheduler、云端 provider
和各备份项目的动态事实；复制到这里会在下一次运行后立即过期。

GitHub 总索引只负责仓库级备份治理：目标仓库身份、visibility、remote、分支、
候选提交与公开发布边界。需要判断真实备份是否完成时，必须读取对应 owner 的新鲜
回执；本页存在不构成备份成功证据。

历史备份快照仍可从 Git 历史追溯，但只能按其 `observed_at` 解释。
