# 本机配置状态（派生导航）

- `document_role=derived_navigation`
- `authoritative=false`
- `derived_from=E:\PCConfig`
- `observed_at=none`
- `freshness=not_a_snapshot`
- `expires_after=immediate`

本仓库不再复制 E 盘根目录数量、路径、端口、运行时、迁移候选、恢复状态或
Password Center 运行事实。它们会随主机和时间变化，当前权威始终是 PCConfig 的
实时 provider/registry 与现场回读；仅当 Git 决策实际依赖这些机器事实时才按需查询。

本页只保留旧链接兼容性和 owner 边界：

- `.agents`：Agent 行为与能力路由；
- PCConfig：机器配置、任务、路径、端口、运行时、备份与恢复事实；
- GitHub 总索引：仓库身份、remote、visibility、worktree、同步与发布治理；
- 具体项目：业务语义、源码、测试与部署方式。

历史机器快照仍可从 Git 历史读取，但只作为带日期证据，不得恢复为当前规则或
当前机器事实。
