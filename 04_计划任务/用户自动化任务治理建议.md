# 用户自动化计划任务治理（路由页）

- `document_role=owner_routing`
- `authoritative=false`
- `derived_from=Windows Task Scheduler + E:\PCConfig`
- `observed_at=none`
- `freshness=not_a_snapshot`
- `expires_after=immediate`

本仓库不再维护计划任务名称、Action、时间表、返回码、隐藏窗口实现或重建顺序的
第二份当前清单。稳定 owner 分工如下：

- Windows Task Scheduler：当前运行态；
- PCConfig：机器配置、公开安全用途索引、恢复顺序与只读验证入口；
- 所属项目：任务的业务目的、脚本行为和结果解释；
- GitHub 总索引：只保留与仓库同步/发布有关的公开治理边界，不拥有任务事实。

需要治理计划任务时，从 PCConfig 的 live provider/registry 开始；不得从本页或其
Git 历史恢复旧时间表、旧路径或已退役任务。公开输出仍禁止完整 task XML、敏感
参数、原始日志、私密截图和机器快照。
